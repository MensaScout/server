# MensaScout Server
Middleware for [the client](https://github.com/MensaScout/client) written in Swift

## Background
As I implemented the features in the client for the first version, it became increasingly difficult to move forward.

I tried to do too much right from the start.

## Goal of the first Version
Therefore, the goal of the first version is to have all the (really) necessary functionality without any bloat.

This includes the following domain objects:
- Canteen
- CanteenOperator
- Meal
- Address
